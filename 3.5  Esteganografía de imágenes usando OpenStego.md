# 🔵 PRÁCTICA 3.5 — Task 5: Esteganografía de imágenes con OpenStego y StegOnline

**Image Steganography using OpenStego and StegOnline** *(Esteganografía de imágenes usando OpenStego y StegOnline)*

### Explicación del ataque (para decir en el video)

La esteganografía es diferente a cifrar algo: en vez de encriptar el mensaje para que se vea como basura, lo que hago es esconderlo dentro de otra cosa que parece totalmente inocente — en este caso, dentro de una imagen. Cualquiera que vea la foto solo ve una foto normal, no sabe que dentro tiene un archivo de texto con información sensible escondido en los bits de los píxeles. Voy a hacerlo primero con un programa llamado OpenStego, que además permite poner contraseña al mensaje escondido, y después voy a repetir la idea con una herramienta web llamada StegOnline, que deja jugar directamente con los bits de la imagen.

## 1️⃣ Preparación

**1.1 —** Primero enciendo la **Máquina Víctima** e inicio sesión con el usuario y la contraseña de la Víctima.

**1.2 —** Confirmo que el adaptador de red de la Máquina Víctima esté en modo **NAT**. Voy a **VM → Settings (Configuración) → Network Adapter (Adaptador de red)** y selecciono **NAT**, para tener salida a internet durante esta práctica.

> Como esta máquina venía en Host-only y la cambié a NAT, cambiar el adaptador en VM Settings no actualizó por sí solo la IP dentro de Windows — tuve que entrar también a la configuración de red de Windows. Voy a **Panel de control → Centro de redes y recursos compartidos → Cambiar configuración del adaptador**, clic derecho en la conexión → **Propiedades**, entro a **Protocolo de Internet versión 4 (TCP/IPv4) → Propiedades**, y marco las dos opciones automáticas: **"Obtener una dirección IP automáticamente"** y **"Obtener la dirección del servidor DNS automáticamente"**. Después abro una consola (cmd) y corro `ipconfig /release` y `ipconfig /renew`. Confirmo con `ping google.com` que ya tengo internet.

**1.3 —** Muestro en cámara usuario, fecha y hora *(rúbrica)*.

> El manual pide usar el usuario **Administrator (Administrador)** con contraseña **Pa$$w0rd** en Windows Server 2019 — en mi caso uso mi propio usuario de la Máquina Víctima, siguiendo los mismos pasos del resto del manual.

## 2️⃣ Preparar los archivos (adaptación — no tengo la carpeta Z:\ del CEH)

Como confirmé que no tengo la unidad de red `Z:` con los archivos de ejemplo del manual (`Island.jpg`, `New Text Document.txt`), los creo yo mismo:

**2.1 —** Creo una carpeta en el Escritorio llamada `OpenStego`, para tener todo organizado, igual que en la ruta del manual.

**2.2 —** Guardo ahí una imagen en formato `.jpg`, `.png` o `.bmp` — esta va a ser mi **cover file (archivo de portada/cubierta)**, equivalente al `Island.jpg` del manual. No tiene que ser una foto mía: puede ser cualquier imagen bajada de Google (en mi caso usé una foto de la Catedral de San Basilio, `rusia_1280x720.jpg`).

**2.3 —** Creo un archivo de texto nuevo — clic derecho → **New (Nuevo)** → **Text Document (Documento de texto)** — en esa misma carpeta, y escribo dentro información que simule ser sensible.

> Nota del manual: *"Assume the text file contains sensitive information such as credit card and pin numbers"* (Asumir que el archivo de texto contiene información sensible como números de tarjeta de crédito y pin) — el manual usa como ejemplo `VISA: 12xx xxxx xxxx xx89` y `pin: 1xx4`. Escribo algo similar, usando datos ficticios.

**2.4 —** Este archivo de texto es mi **message file (archivo de mensaje)**, equivalente al `New Text Document.txt` del manual.

## 3️⃣ Descargar e instalar OpenStego

**3.1 —** Internet Explorer 8, el navegador por defecto de este Windows, es demasiado viejo para varios sitios modernos, incluyendo el de descargas de OpenStego. Así que antes de continuar, instalo **Firefox ESR (Soporte Extendido)**, la última versión de Firefox compatible con Windows 7:

- Voy a `https://ftp.mozilla.org/pub/firefox/releases/115.26.0esr/win32/es-ES/`
- Descargo **Firefox Setup 115.26.0esr.exe** y lo ejecuto con las opciones por defecto: **Next (Siguiente) → Next (Siguiente) → Finish (Finalizar)**.

**3.2 —** Abro Firefox y voy a `https://www.openstego.com/` — la página oficial de OpenStego no tiene un enlace de descarga directo, y el link a SourceForge tampoco funciona, así que lo descargo desde el repositorio oficial en GitHub:

```
https://github.com/syvaidya/openstego/releases
```

**3.3 —** En la versión más reciente (por ejemplo OpenStego v0.8.6), busco en la sección **Assets (Archivos adjuntos)** el archivo que empieza con `Setup-OpenStego` y termina en `.exe` — por ejemplo `Setup-OpenStego-0.8.6.exe` — y hago clic para descargarlo.

**3.4 —** Ejecuto el instalador descargado. Sale una advertencia de seguridad de Windows: *"No se pudo comprobar el editor"* — es normal en software sin firma digital, así que hago clic en **Ejecutar**.

**3.5 —** En la ventana **Select Setup Install Mode (Seleccionar modo de instalación)**, elijo **Install for me only — recommended (Instalar solo para mí — recomendado)**. Luego acepto la licencia marcando **I accept the agreement (Acepto el acuerdo)**, y continúo el asistente con las opciones por defecto: **Next (Siguiente) → Next (Siguiente) → Install (Instalar) → Finish (Finalizar)**.

**3.6 —** OpenStego es una aplicación en Java y necesita el Java Runtime (Entorno de ejecución de Java) instalado. Si al abrirlo me sale el error *"ERROR: JAVA_HOME is not set and no 'java' command could be found in your PATH"* (Error: JAVA_HOME no está configurado y no se encontró el comando 'java' en el PATH), instalo Java:

- En Firefox, voy a `https://www.java.com/es/download/`
- Hago clic en **Descargar Java para escritorios** y ejecuto el instalador con las opciones por defecto.
- Cuando termina, vuelvo a abrir OpenStego.

## 4️⃣ Abrir OpenStego y ocultar el mensaje (Hide Data)

**4.1 —** Busco `openstego` en el buscador de Windows y lo abro (el manual usa el ícono de búsqueda del Escritorio; en mi caso es el menú Inicio → escribir `openstego`).

**4.2 —** Se abre la ventana principal de **OpenStego**, con las opciones **Data hiding (Ocultamiento de datos)** — que tiene **Hide data (Ocultar datos)** y **Extract data (Extraer datos)** — y **Digital watermarking (Marca de agua digital)**.

**4.3 —** Hago clic en el botón de puntos suspensivos (**...**) junto a **Message File (Archivo de mensaje)**.

**4.4 —** Navego hasta mi carpeta `OpenStego` en el Escritorio, selecciono el archivo de texto que creé, y hago clic en **Open (Abrir)**. La ruta aparece en el campo **Message File**.

**4.5 —** Hago clic en el botón de puntos suspensivos (**...**) junto a **Cover File (Archivo de portada)**.

**4.6 —** Navego a la misma carpeta, selecciono mi imagen `rusia_1280x720.jpg`, y hago clic en **Open (Abrir)**.

**4.7 —** Ahora que **Message File** y **Cover File** están cargados, hago clic en el botón de puntos suspensivos (**...**) junto a **Output Stego File (Archivo de salida esteganografiado)**.

**4.8 —** En la ventana **Save - Select output stego file (Guardar - Seleccionar archivo de salida esteganografiado)**, elijo guardar en el **Escritorio** — no dentro de la carpeta `OpenStego` — escribo el nombre `Stego` y hago clic en **Open (Abrir/Guardar)**. El archivo queda como `Stego.bmp`.

**4.9 —** En la ventana de OpenStego, hago clic en el botón **Hide data (Ocultar datos)**.

**4.10 —** Aparece una ventana emergente de **Success (Éxito)** confirmando que el mensaje se ocultó correctamente; hago clic en **OK (Aceptar)**.

## 5️⃣ Verificar que el mensaje quedó oculto

**5.1 —** Minimizo OpenStego. En el Escritorio aparece la imagen `Stego.bmp`. Le hago doble clic para verla.

**5.2 —** Veo la imagen normal, sin rastro visible del mensaje escondido dentro.

**5.3 —** Cierro el visor de imágenes.

## 6️⃣ Extraer el mensaje oculto (Extract Data)

**6.1 —** En la ventana de OpenStego, hago clic en **Extract data (Extraer datos)** en el panel izquierdo.

**6.2 —** Hago clic en el botón de puntos suspensivos (**...**) junto a **Input Stego File (Archivo esteganografiado de entrada)**.

**6.3 —** Navego al Escritorio, selecciono `Stego.bmp`, y hago clic en **Open (Abrir)**.

**6.4 —** Hago clic en el botón de puntos suspensivos (**...**) junto a **Output folder for message file (Carpeta de salida para el archivo de mensaje)**.

**6.5 —** Elijo el Escritorio como carpeta destino y hago clic en **Open (Abrir)**.

**6.6 —** Hago clic en el botón **Extract data (Extraer datos)**.

**6.7 —** Aparece una ventana **Success (Éxito)** confirmando que el archivo de mensaje se extrajo correctamente de la imagen; hago clic en **OK (Aceptar)**.

**6.8 —** El archivo de texto extraído aparece en el Escritorio.

**6.9 —** Cierro OpenStego, voy al Escritorio, y le hago doble clic al archivo de texto extraído.

**6.10 —** El archivo muestra toda la información que escribí originalmente — esto confirma que el mensaje viajó escondido dentro de la imagen y se pudo recuperar intacto.

> Nota del manual: *"In real-time, an attacker might scan for images that contain hidden information and use steganography tools to decrypt their hidden information."* (En tiempo real, un atacante podría escanear imágenes en busca de información oculta y usar herramientas de esteganografía para descifrarla.)

## 7️⃣ Repetir con StegOnline (herramienta web)

**7.1 —** Abro un navegador, y en la barra de direcciones escribo:

```
https://stegonline.georgeom.net/upload
```

**7.2 —** En la página de **StegOnline**, hago clic en el botón **UPLOAD IMAGE (Subir imagen)**.

**7.3 —** En la ventana de subida, selecciono mi imagen original `rusia_1280x720.jpg` — la misma que usé como cover file, sin el mensaje escondido — y hago clic en **Open (Abrir)**.

**7.4 —** En la página **Image Options (Opciones de imagen)**, hago clic en el botón **Embed Files/Data (Incrustar archivos/datos)**.

**7.5 —** En la página **Embed Data (Incrustar datos)**, marco las casillas de la **fila 5** en las columnas **R (Rojo)**, **G (Verde)** y **B (Azul)**.

> Cuidado: es la fila **5**, no la fila 4 — verifico bien el número a la izquierda de cada fila antes de marcar.

**7.6 —** Bajo hasta el campo **Input Data (Datos de entrada)**, confirmo que el tipo esté en **Text (Texto)**, y escribo:

```
Hello World!!!
```

**7.7 —** Hago clic en **Go (Ir/Continuar)**.

**7.8 —** Bajo para ver la imagen resultante en la sección **Output (Salida)**, y hago clic en **Download Extracted Data (Descargar datos extraídos)** para guardarla.

> En Firefox, este botón descarga el archivo directamente a la carpeta **Descargas**, sin preguntar dónde guardarlo — a diferencia del manual, que asume una ventana de "Guardar como". El archivo se descarga como una imagen `.png` con el mismo nombre de la imagen original, es decir, queda como `rusia_1280x720.png`.

**7.9 —** Voy a la carpeta **Descargas**, corto el archivo descargado — clic derecho → **Cut (Cortar)** — y lo pego en el **Escritorio**, para tenerlo ordenado junto a los demás archivos de la práctica.

## 8️⃣ Extraer los datos con StegOnline

**8.1 —** Abro una nueva pestaña en el navegador, y voy otra vez a `https://stegonline.georgeom.net/upload`.

**8.2 —** Hago clic en **UPLOAD IMAGE (Subir imagen)** y selecciono desde el Escritorio la imagen `rusia_1280x720.png` que descargué en el paso 7.9 — la que contiene el mensaje incrustado.

**8.3 —** En **Image Options (Opciones de imagen)**, hago clic en **Extract Files/Data (Extraer archivos/datos)**.

**8.4 —** En la página **Extract Data (Extraer datos)**, marco las casillas de la **fila 5** en las columnas **R (Rojo)**, **G (Verde)** y **B (Azul)** — igual que al incrustarlo — bajo y hago clic en **Go (Ir/Continuar)**.

**8.5 —** Bajo hasta la sección **Results (Resultados)** para ver el texto extraído.

> Nota del manual: los resultados solo muestran los primeros 2500 bytes; para obtener todo el contenido hay que usar el botón **Download (Descargar)**. En mi caso, en la sección **"Ascii (readable only)" ("Ascii — solo legible")** se ve el texto `Hello World!!!` que escondí.

## 9️⃣ Cierre de la práctica

**9.1 —** Con esto concluyo la demostración de cómo realizar esteganografía de imágenes usando OpenStego y StegOnline.

**9.2 —** El manual menciona que también existen otras herramientas de esteganografía de imágenes, que puedo mencionar como referencia adicional (no es necesario usarlas): **QuickStego** (quickcrypto.com), **SSuite Picsel** (ssuitesoft.com), **CryptaPix** (briggsoft.com) y **gifshuffle** (darkside.com.au).

**9.3 —** Cierro todas las ventanas abiertas y documento toda la información adquirida, incluyendo los errores que encontré y resolví durante la práctica: no tener la carpeta `Z:\` del CEH, la incompatibilidad de Internet Explorer 8 con los sitios de descarga, y tener que instalar Firefox ESR y Java para que OpenStego funcionara.

**9.4 —** Apago la Máquina Víctima, equivalente a "apagar la máquina Windows Server 2019" del manual.

**4.7 —** Ahora que **Message File** y **Cover File** están cargados, hago clic en el botón de puntos suspensivos (**...**) junto a **Output Stego File (Archivo de salida esteganografiado)**.

**4.8 —** En la ventana **Save - Select output stego file (Guardar - Seleccionar archivo de salida esteganografiado)**, elijo guardar en el **Escritorio** — no dentro de la carpeta `OpenStego` — escribo el nombre `Stego` y hago clic en **Open (Abrir/Guardar)**. El archivo queda como `Stego.bmp`.

**4.9 —** En la ventana de OpenStego, hago clic en el botón **Hide data (Ocultar datos)**.

**4.10 —** Aparece una ventana emergente de **Success (Éxito)** confirmando que el mensaje se ocultó correctamente; hago clic en **OK (Aceptar)**.

## 5️⃣ Verificar que el mensaje quedó oculto

**5.1 —** Minimizo OpenStego. En el Escritorio aparece la imagen `Stego.bmp`. Le hago doble clic para verla.

**5.2 —** Veo la imagen normal, sin rastro visible del mensaje escondido dentro.

**5.3 —** Cierro el visor de imágenes.

## 6️⃣ Extraer el mensaje oculto (Extract Data)

**6.1 —** En la ventana de OpenStego, hago clic en **Extract data (Extraer datos)** en el panel izquierdo.

**6.2 —** Hago clic en el botón de puntos suspensivos (**...**) junto a **Input Stego File (Archivo esteganografiado de entrada)**.

**6.3 —** Navego al Escritorio, selecciono `Stego.bmp`, y hago clic en **Open (Abrir)**.

**6.4 —** Hago clic en el botón de puntos suspensivos (**...**) junto a **Output folder for message file (Carpeta de salida para el archivo de mensaje)**.

**6.5 —** Elijo el Escritorio como carpeta destino y hago clic en **Open (Abrir)**.

**6.6 —** Hago clic en el botón **Extract data (Extraer datos)**.

**6.7 —** Aparece una ventana **Success (Éxito)** confirmando que el archivo de mensaje se extrajo correctamente de la imagen; hago clic en **OK (Aceptar)**.

**6.8 —** El archivo de texto extraído aparece en el Escritorio.

**6.9 —** Cierro OpenStego, voy al Escritorio, y le hago doble clic al archivo de texto extraído.

**6.10 —** El archivo muestra toda la información que escribí originalmente — esto confirma que el mensaje viajó escondido dentro de la imagen y se pudo recuperar intacto.

> Nota del manual: *"In real-time, an attacker might scan for images that contain hidden information and use steganography tools to decrypt their hidden information."* (En tiempo real, un atacante podría escanear imágenes en busca de información oculta y usar herramientas de esteganografía para descifrarla.)
> 

## 7️⃣ Repetir con StegOnline (herramienta web)

**7.1 —** Abro un navegador, y en la barra de direcciones escribo:

```
<https://stegonline.georgeom.net/upload>
```

**7.2 —** En la página de **StegOnline**, hago clic en el botón **UPLOAD IMAGE (Subir imagen)**.

**7.3 —** En la ventana de subida, selecciono mi imagen original `rusia_1280x720.jpg` — la misma que usé como cover file, sin el mensaje escondido — y hago clic en **Open (Abrir)**.

**7.4 —** En la página **Image Options (Opciones de imagen)**, hago clic en el botón **Embed Files/Data (Incrustar archivos/datos)**.

**7.5 —** En la página **Embed Data (Incrustar datos)**, marco las casillas de la **fila 5** en las columnas **R (Rojo)**, **G (Verde)** y **B (Azul)**.

> Cuidado: es la fila **5**, no la fila 4 — verifico bien el número a la izquierda de cada fila antes de marcar.
> 

**7.6 —** Bajo hasta el campo **Input Data (Datos de entrada)**, confirmo que el tipo esté en **Text (Texto)**, y escribo:

```
Hello World!!!
```

**7.7 —** Hago clic en **Go (Ir/Continuar)**.

**7.8 —** Bajo para ver la imagen resultante en la sección **Output (Salida)**, y hago clic en **Download Extracted Data (Descargar datos extraídos)** para guardarla.

> En Firefox, este botón descarga el archivo directamente a la carpeta **Descargas**, sin preguntar dónde guardarlo — a diferencia del manual, que asume una ventana de "Guardar como". El archivo se descarga como una imagen `.png` con el mismo nombre de la imagen original, es decir, queda como `rusia_1280x720.png`.
> 

**7.9 —** Voy a la carpeta **Descargas**, corto el archivo descargado — clic derecho → **Cut (Cortar)** — y lo pego en el **Escritorio**, para tenerlo ordenado junto a los demás archivos de la práctica.

## 8️⃣ Extraer los datos con StegOnline

**8.1 —** Abro una nueva pestaña en el navegador, y voy otra vez a `https://stegonline.georgeom.net/upload`.

**8.2 —** Hago clic en **UPLOAD IMAGE (Subir imagen)** y selecciono desde el Escritorio la imagen `rusia_1280x720.png` que descargué en el paso 7.9 — la que contiene el mensaje incrustado.

**8.3 —** En **Image Options (Opciones de imagen)**, hago clic en **Extract Files/Data (Extraer archivos/datos)**.

**8.4 —** En la página **Extract Data (Extraer datos)**, marco las casillas de la **fila 5** en las columnas **R (Rojo)**, **G (Verde)** y **B (Azul)** — igual que al incrustarlo — bajo y hago clic en **Go (Ir/Continuar)**.

**8.5 —** Bajo hasta la sección **Results (Resultados)** para ver el texto extraído.

> Nota del manual: los resultados solo muestran los primeros 2500 bytes; para obtener todo el contenido hay que usar el botón **Download (Descargar)**. En mi caso, en la sección **"Ascii (readable only)" ("Ascii — solo legible")** se ve el texto `Hello World!!!` que escondí.
>
