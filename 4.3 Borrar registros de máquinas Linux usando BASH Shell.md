# 🔵 PRÁCTICA 4.3 — Task 3: Borrar registros de máquinas Linux usando BASH Shell

**Clear Linux Machine Logs using the BASH Shell** *(Borrar registros de máquinas Linux usando la Shell BASH)*

### Explicación del ataque (para decir en el video)

Esta práctica también es sobre "cubrir huellas" (covering tracks), pero ahora del lado de Linux. BASH (Bourne Again Shell) guarda un historial de todos los comandos que escribo, en un archivo llamado `bash_history`, que se puede ver con `more ~/.bash_history`. Ese historial es un problema para un atacante, porque un investigador forense podría revisarlo y reconstruir exactamente qué comandos usó el intruso para comprometer el sistema. Voy a mostrar varias formas de borrar o inutilizar ese historial: desactivando que se guarde desde el inicio, borrando lo ya guardado, y hasta "triturando" el archivo para que ni siquiera se pueda leer si alguien lo recupera.

## 1️⃣ Preparación

**1.1 —** Enciendo mi máquina **Kali**.

**1.2 —** En la pantalla de inicio de sesión, entro con el usuario `kali` (en el manual sería el usuario `attacker`/`toor` de Parrot Security).

**1.3 —** Muestro en cámara usuario, fecha y hora *(rúbrica)*.

**1.4 —** Abro una terminal.

## 2️⃣ Desactivar que BASH guarde el historial

**2.1 —** En la terminal, escribo el siguiente comando y presiono **Enter**:

```
export HISTSIZE=0
```

> Nota del manual: `HISTSIZE` (tamaño del historial) determina cuántos comandos se guardan — al ponerlo en `0`, deshabilito que la shell BASH siga guardando el historial de ahora en adelante.
> 

## 3️⃣ Borrar el historial ya guardado

**3.1 —** Escribo el siguiente comando y presiono **Enter**:

```
history -c
```

> Nota del manual: `history -c` (clear, borrar) es una alternativa efectiva al comando de desactivar el historial — con `history -c` tengo la ventaja de poder seguir reescribiendo o revisando los comandos anteriores usados en la sesión antes de borrarlos.
> 

> Nota del manual: de forma similar, también se puede usar el comando `history -w` (write, escribir) para borrar el historial de la shell actual, sin afectar el historial de otras shells abiertas.
> 

## 4️⃣ Triturar el archivo del historial con shred

**4.1 —** Escribo el siguiente comando y presiono **Enter**:

```
shred ~/.bash_history
```

> Nota del manual: `shred` (triturar) hace que el contenido del archivo `.bash_history` quede ilegible. Esto es útil en los casos donde un investigador logra localizar el archivo, porque gracias a este comando no va a poder leer ningún contenido dentro de él.
> 

**4.2 —** Para comprobarlo, escribo el siguiente comando y presiono **Enter**:

```
more ~/.bash_history
```

**4.3 —** En vez de comandos legibles, veo puro contenido triturado — símbolos y caracteres sin sentido, confirmando que el archivo quedó inutilizable.

**4.4 —** Como el archivo puede ser largo, `more` lo muestra por partes y se queda esperando (aparece `--More--` con un porcentaje abajo). Presiono **Ctrl+Z** para dejar de ver el contenido triturado.

> Nota del manual: el tiempo que toma triturar el archivo del historial depende de su tamaño.
> 

## 5️⃣ Hacer todo en un solo comando

**5.1 —** Puedo combinar todos los comandos anteriores en uno solo, escribiendo lo siguiente y presionando **Enter**:

```
shred ~/.bash_history && cat /dev/null > .bash_history && history -c && exit
```

> Nota del manual: este comando primero tritura el archivo del historial, después lo vacía por completo (lo deja en blanco), luego borra el historial de la sesión actual, y finalmente cierra la terminal — borrando así hasta la evidencia de haber usado este mismo comando.
>

**6.2 —** Cierro todas las ventanas abiertas y documento toda la información adquirida.
